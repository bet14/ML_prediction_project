3. Current findings / open issues

FINDING
FTSE All-Share ticker (^FTAS) not live-confirmed — inferred from the same Yahoo FTSE-family naming pattern as ^FTSE/^FTMC/^FTLC and from the Reuters RIC convention ".FTAS", but two direct verification attempts both returned empty bodies in this sandbox: the HTML quote page (finance.yahoo.com/quote/%5EFTAS — JS-rendered SPA, raw fetch sees no content) and the underlying chart JSON API (query1.finance.yahoo.com/.../chart/%5EFTAS — likely blocked by Yahoo's cookie/crumb requirement for unauthenticated callers). Spot-check yf.Ticker("^FTAS").history(period="5d") first when running on a personal machine.
NOT A BLOCKER
The empty-fetch results above are a sandbox/anti-bot limitation, not evidence the ticker is wrong — yfinance (the package this project actually depends on) handles Yahoo's session/crumb negotiation internally, unlike the bare requests calls used to probe this manually.
NO CONCERN
Unlike forex, equity index volume on Yahoo Finance is genuine traded share volume — no data-quality caveat analogous to the FX-volume issue in reports/forex_data_status.html.
